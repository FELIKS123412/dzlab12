# Домашнее задание к работе 12

## Условие задачи

Разработайте программу, которая записывает в файл поля структуры ДЗ работы 11

Создать структуру для хранения записи «Автобусный маршрут».

Поля записи:

номер маршрута
начальная остановка
конечная остановка
длина маршрута в километрах
количество остановок

Вычислить среднее расстояние между остановками для каждого маршрута и вывести сведения о маршрутах, где оно меньше заданного значения.

---

## 1. Алгоритм 

### Алгоритм

1. Задать константы: количество маршрутов `COUNT = 3` и имя выходного файла `FILENAME = "routes.txt"`.
2. Описать структуру `Busroute` со всеми полями записи о маршруте (`number`, `startroad`, `stoproad`, `length`, `stopcount`).
3. Настроить локализацию (`setlocale`) для корректной работы с русским языком в консоли.
4. В цикле от `0` до `2` считать с клавиатуры данные для 3 маршрутов: номер маршрута, начальную и конечную остановки (одно слово без пробелов), длину маршрута в километрах и количество остановок.
5. Считать с клавиатуры пороговое значение среднего расстояния между остановками (`treshholdvalue`).
6. Вызвать функцию `process_routes(routes, COUNT, treshholdvalue)`:
   - для каждого маршрута рассчитать среднее расстояние между остановками через `calculate_distance` (если `stopcount <= 1`, вернуть `0.0`, иначе вычислить `length / (stopcount - 1)`);
   - вывести на экран все 3 маршрута через `print_route`;
   - отдельно вывести маршруты, у которых среднее расстояние меньше `threshold` и количество остановок больше `1` (или сообщение, если таких маршрутов нет).
7. Запросить у пользователя режим работы с файлом (`choice`): `1` — запись в новый файл с перезаписью (`"w"`), `2` — дозапись в существующий файл (`"a"`). При ошибке ввода или выборе другого значения вывести сообщение об ошибке и завершить программу с кодом `1`.
8. Вызвать функцию `writefile(FILENAME, routes, COUNT, mode)` с выбранным режимом (`"w"` или `"a"`):
   - открыть файл `routes.txt` в указанном режиме; если указатель `out == NULL`, вывести сообщение об ошибке и вернуть `0`;
   - в цикле по всем записям рассчитать `dist` и записать поля структуры в файл через `fprintf` (после каждого поля ставятся `;` и `\n`, записи разделяются `\n\n`); при ошибке записи (`< 0`) вывести сообщение, закрыть файл и вернуть `0`;
   - закрыть файл функцией `fclose` и вернуть `1`.
9. По результату `writefile` вывести сообщение об успешной записи (или дозаписи) данных в файл либо об ошибке и завершить программу.
